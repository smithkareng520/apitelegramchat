我目前在这个对话里可以调用的工具大致可以分成这几类，我按功能分组列出工具的函数名：

**信息检索 / 搜索**
- `web_search` — 网页搜索
- `web_fetch` — 抓取指定网页内容
- `image_search` — 图片搜索
- `places_search` — 地点/商家搜索（Google Places）
- `fetch_sports_data` — 体育赛事比分/数据

**记忆系统（跨对话持久化）**
- `memory_read`
- `memory_write`
- `memory_str_replace`
- `memory_append`
- `memory_delete`
- `memory_list`

**电脑/文件操作（沙盒环境）**
- `bash_tool` — 执行 bash 命令
- `create_file` — 新建文件
- `str_replace` — 编辑文件内容
- `view` — 查看文件/目录/图片
- `present_files` — 把文件展示给用户

**可视化 / 交互式卡片（聊天内嵌组件）**
- `chart_display_v0` — 简单折线/柱状/散点图
- `visualize:read_me` / `visualize:show_widget` — SVG/HTML 图表、交互组件
- `comparison_card_display_v0` — 产品对比卡
- `featured_card_display_v0` — 单一推荐卡
- `product_carousel_display_v0` — 多产品轮播卡
- `options_card_display_v0` — 方案选项卡（如健康建议）
- `step_card_display_v0` — 步骤引导卡
- `itinerary_display_v0` — 行程时间线
- `places_list_display_v0` / `places_map_display_v0` — 地点列表/地图
- `recipe_display_v0` — 菜谱卡（可调份量）
- `quiz_display_v0` — 测验/闪卡
- `translation_display_v0` — 翻译对照卡
- `link_preview_display_v0` — 链接预览卡
- `message_compose_v1` — 邮件/消息草稿生成
- `weather_fetch` — 天气查询

**用户交互辅助**
- `ask_user_input_v0` — 提供可点选按钮收集偏好

**第三方连接与插件相关**
- `search_mcp_registry` — 搜索可连接的第三方服务
- `suggest_connectors` — 展示连接选项
- `search_plugins` / `suggest_plugin_install` — 插件搜索与安装建议
- `search_skills` / `suggest_skills` — 技能搜索与添加建议
- `show_recommendation_cards` — 推荐 Claude 其他客户端/应用（如 Claude Code、Excel 插件等）

**其他**
- `end_conversation` — 在特定情况下结束对话
